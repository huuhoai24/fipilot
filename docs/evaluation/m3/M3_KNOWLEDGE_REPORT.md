## Normalized schema

Chunk records contain `id`, `domain`, `topic`, `subtopic`, `level`, `content_type`, `title`, `content`, `source_path`, `source_heading`, `source_start_line`, `source_end_line`, `version`, `content_hash`, and `metadata`. Domain aliases are explicit; unknown domains fail. Levels are limited to Intern, Junior, Middle, Senior, and `unspecified`.

## Chunking strategy

- Hierarchy: source kind → domain → path topic/subtopic → Markdown heading hierarchy → semantic section → bounded chunk.
- Target/max/min: `400` / `600` / `30` approximate tokens.
- Counter: deterministic Unicode regex approximation (`\w+|[^\w\s]`), explicitly not a model tokenizer.
- Overlap: only sections exceeding the maximum; bounded prefix of up to `50` approximate tokens.
- Heading-only documents are preserved using a labelled `title_fallback` chunk instead of being silently omitted.
