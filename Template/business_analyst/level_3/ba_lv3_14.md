# Bộ Câu Hỏi Phỏng Vấn Business Analyst (Level 3) - Digital Transformation & Automation (14)

* **Role:** Business Analyst
* **Level:** Level 3
* **Experience:** 4 - 5 năm kinh nghiệm

---

## CÂU HỎI DỄ (3 câu - Trọng số: 0.1 / câu)

### Câu 1
* **Độ khó:** Dễ
* **Câu hỏi:** RPA (Robotic Process Automation) là gì? BA đánh giá process nào suitable cho RPA bằng criteria nào?
* **expected_key_points:**
  - id: KP1
    content: RPA definition và use cases
    keypoint_weight: 0.35
    description: Software robots tự động hóa tasks lặp đi lặp lại, rule-based, tương tác với UI. VD: data entry, report generation.
  - id: KP2
    content: Suitability criteria
    keypoint_weight: 0.35
    description: High volume, rule-based, stable process, structured data, manual effort > 2 FTE, low exception rate.
  - id: KP3
    content: BA deliverables cho RPA
    keypoint_weight: 0.3
    description: Process Definition Document (PDD), Solution Design Document (SDD), exception handling flows.

### Câu 2
* **Độ khó:** Dễ
* **Câu hỏi:** Phân biệt Automation, Digitization, và Digital Transformation. BA role trong mỗi mức độ.
* **expected_key_points:**
  - id: KP1
    content: Digitization: analog to digital
    keypoint_weight: 0.35
    description: Chuyển đổi tài liệu giấy sang digital. BA: document data capture requirements, storage, retrieval.
  - id: KP2
    content: Automation: process efficiency
    keypoint_weight: 0.35
    description: Tự động hóa manual steps trong existing process. BA: process analysis, automation opportunity assessment.
  - id: KP3
    content: Digital Transformation: business model change
    keypoint_weight: 0.3
    description: Thay đổi cách thức kinh doanh fundamentally. BA: strategic analysis, new capability requirements, change management.

### Câu 3
* **Độ khó:** Dễ
* **Câu hỏi:** Low-code/No-code platforms: ưu nhược điểm gì? BA đánh giá khi nào nên dùng?
* **expected_key_points:**
  - id: KP1
    content: Ưu điểm: speed to market
    keypoint_weight: 0.35
    description: Rapid prototyping, citizen development, reduced IT backlog, visual development.
  - id: KP2
    content: Nhược điểm: limitations
    keypoint_weight: 0.35
    description: Vendor lock-in, scalability limits, customization constraints, governance challenges.
  - id: KP3
    content: Evaluation criteria
    keypoint_weight: 0.3
    description: Complexity level, integration needs, scalability requirements, long-term maintenance, security compliance.

## CÂU HỎI TRUNG BÌNH (4 câu - Trọng số: 0.1 / câu)

### Câu 4
* **Độ khó:** Trung bình
* **Câu hỏi:** Bạn lead automation assessment cho department có 50 processes. Mô tả approach từ discovery đến prioritization.
* **expected_key_points:**
  - id: KP1
    content: Process inventory và documentation
    keypoint_weight: 0.25
    description: Catalog all processes: volume, frequency, FTE effort, systems used, pain points.
  - id: KP2
    content: Automation feasibility scoring
    keypoint_weight: 0.3
    description: Score matrix: complexity (low=high score), volume (high=high score), standardization, system stability.
  - id: KP3
    content: Benefit estimation
    keypoint_weight: 0.25
    description: FTE savings, error reduction, cycle time improvement, compliance improvement per process.
  - id: KP4
    content: Phased implementation roadmap
    keypoint_weight: 0.2
    description: Quick wins first (high benefit, low complexity), build capability, tackle complex processes later.

### Câu 5
* **Độ khó:** Trung bình
* **Câu hỏi:** Bạn document Process Definition Document (PDD) cho RPA bot. Mô tả structure và level of detail cần thiết.
* **expected_key_points:**
  - id: KP1
    content: AS-IS process với step-by-step screenshots
    keypoint_weight: 0.3
    description: Mỗi step: action, screen, field, input/output data, decision logic. Screenshot cho mỗi screen interaction.
  - id: KP2
    content: Exception handling matrix
    keypoint_weight: 0.25
    description: All possible exceptions, frequency, current handling method, proposed bot handling logic.
  - id: KP3
    content: Business rules documentation
    keypoint_weight: 0.25
    description: Decision logic at each step, data validation rules, lookup tables, calculation formulas.
  - id: KP4
    content: Volume và SLA requirements
    keypoint_weight: 0.2
    description: Daily/weekly volume, peak periods, processing time SLA, priority rules.

### Câu 6
* **Độ khó:** Trung bình
* **Câu hỏi:** Bạn phân tích yêu cầu cho Intelligent Document Processing (IDP) system. Approach và key considerations?
* **expected_key_points:**
  - id: KP1
    content: Document classification requirements
    keypoint_weight: 0.25
    description: Document types, volumes, formats (PDF, scan, email). Classification accuracy thresholds.
  - id: KP2
    content: Data extraction rules
    keypoint_weight: 0.3
    description: Fields to extract per document type, validation rules, confidence thresholds, human review triggers.
  - id: KP3
    content: Integration với downstream systems
    keypoint_weight: 0.25
    description: Where extracted data goes, format requirements, approval workflows, exception routing.
  - id: KP4
    content: Continuous learning requirements
    keypoint_weight: 0.2
    description: Feedback loop for model improvement, retraining triggers, accuracy monitoring dashboards.

### Câu 7
* **Độ khó:** Trung bình
* **Câu hỏi:** Bạn thiết kế workflow automation cho HR onboarding process spanning 6 systems. Mô tả requirements và integration points.
* **expected_key_points:**
  - id: KP1
    content: End-to-end onboarding workflow
    keypoint_weight: 0.3
    description: Offer → contract → IT provisioning → training → compliance → first day checklist. Timeline và dependencies.
  - id: KP2
    content: System integration requirements
    keypoint_weight: 0.25
    description: HRIS, IT ticketing, email/calendar, LMS, badge/access system, payroll. Data flow between systems.
  - id: KP3
    content: Role-based task assignment
    keypoint_weight: 0.25
    description: Tasks cho HR, IT, hiring manager, new employee. SLA cho each task, escalation rules.
  - id: KP4
    content: Compliance và audit requirements
    keypoint_weight: 0.2
    description: I-9 verification, background check, policy acknowledgment tracking, audit trail.
