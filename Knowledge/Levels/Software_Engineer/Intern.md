# Software Engineer - Intern Level Knowledge Depth & Evaluation

### Knowledge Depth

The candidate should:

- Understand the role of a Software Engineer within the Software Development Lifecycle.
- Understand foundational concepts such as program, algorithm, data structure, module, function and object.
- Distinguish among source code, compiled code and interpreted code at a high level.
- Understand the purpose of version control, testing, debugging and documentation.
- Describe the basic flow from requirements to design, development, testing and deployment.
- Understand basic programming principles such as abstraction, encapsulation, modularity and separation of concerns.
- Know the purpose of common data structures such as array, list, stack, queue, hash table and tree.
- Understand time complexity and space complexity at a conceptual level.
- Recognize common errors such as syntax error, runtime error, logical error and null reference.
- Understand authentication, authorization and input validation at a basic level.
- No deep analysis of software architecture or distributed systems is expected.

### Evaluation Focus

- Definitions.
- Purpose.
- Components.
- Software development process.
- Concept differentiation.
- Foundational knowledge of Programming and Software Engineering.
