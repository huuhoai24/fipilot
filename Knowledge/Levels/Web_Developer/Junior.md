# Web Developer - Junior Level Knowledge Depth & Evaluation

### Knowledge Depth

The candidate should understand:

- How browsers parse HTML, CSS and JavaScript to construct and render a web page.
- The Document Object Model, event propagation and browser event handling.
- Responsive design, mobile-first design and common layout mechanisms such as Flexbox and Grid.
- JavaScript execution, scope, closures, asynchronous programming, promises and the event loop.
- Client-side routing, state management and component-based development at a conceptual level.
- HTTP methods, status codes, headers, cookies, sessions and caching.
- REST APIs and JSON-based client–server communication.
- The differences among client-side rendering, server-side rendering and static site generation.
- Basic authentication and authorization mechanisms.
- Same-origin policy, CORS, XSS, CSRF and input validation.
- Browser storage mechanisms such as cookies, local storage and session storage.
- Basic frontend testing, API testing and end-to-end testing concepts.
- Basic performance concepts such as asset size, lazy loading, caching and render-blocking resources.
- Trade-offs among usability, performance, accessibility and development complexity.

### Evaluation Focus

- Browser mechanisms.
- JavaScript fundamentals.
- Responsive design.
- HTTP and API communication.
- Rendering approaches.
- Security fundamentals.
- Testing and performance basics.
- Basic trade-offs.
