# Data Engineer - Intern Level Knowledge Depth & Evaluation

### Knowledge Depth

The candidate should:

- Understand the role of a Data Engineer within the data ecosystem.
- Understand foundational concepts such as database, data warehouse, data lake and ETL/ELT.
- Distinguish among structured, semi-structured and unstructured data.
- Understand the purpose of a data pipeline.
- Describe the data flow from source to consumption.
- Understand basic SQL operations at a conceptual level.
- Understand batch processing and streaming at a high level.
- Know the purpose of partitions, indexes and common file formats.
- Understand data quality, schema and metadata at a basic level.
- Recognize common errors such as missing data, duplicate data and schema mismatch.
- No analysis of distributed systems or data architecture is expected.

### Evaluation Focus

- Definitions.
- Purpose.
- Components.
- Data flow.
- Concept differentiation.
- Foundational knowledge of databases and pipelines.
