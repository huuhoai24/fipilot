# Full Stack Developer - Senior Level Knowledge Depth & Evaluation

### Knowledge Depth

The candidate should:

- Understand the nature and limitations of Full Stack architecture at large scale.
- Translate business objectives into application architecture.
- Build decision frameworks rather than simply selecting a technology.
- Evaluate trade-offs among performance, scalability, reliability, maintainability, security and cost.
- Understand monolith, modular monolith, microservices and BFF architectures based on applicable conditions.
- Evaluate frontend, backend and data architecture as a unified system.
- Understand governance, API governance and architectural consistency.
- Analyze distributed systems, caching strategy, CDN and edge computing based on applicable conditions.
- Evaluate technical debt and long-term maintainability.
- Determine when complex architectures or technologies should not be used.
- Challenge the premise of the problem before making decisions.

### Evaluation Focus

- Nature.
- Limitations.
- Architecture.
- Decision framework.
- Multi-dimensional trade-offs.
- Reliability.
- Security.
- Governance.
- Cost.
- Long-term implications.
- Systems thinking.
- Ability to challenge assumptions.
