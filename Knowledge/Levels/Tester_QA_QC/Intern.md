# Tester QA QC - Intern Level Knowledge Depth & Evaluation

### Knowledge Depth

The candidate should understand:

- The role of QA, QC and Software Testing within the Software Development Lifecycle.
- The differences between Quality Assurance, Quality Control and Testing.
- Fundamental concepts such as defect, bug, failure, error and root cause.
- The purpose of test planning, test execution and defect reporting.
- Basic software testing principles.
- Functional and non-functional testing at a conceptual level.
- Black-box, white-box and gray-box testing.
- Basic test artifacts including test case, test suite, test scenario and bug report.
- Verification vs. validation.
- Basic SDLC and STLC.
- Common software defects and testing terminology.
- No deep knowledge of automation frameworks or testing architecture is expected.

### Evaluation Focus

- Definitions.
- Purpose.
- Testing lifecycle.
- Testing terminology.
- Fundamental concepts.
- Basic testing documents.
