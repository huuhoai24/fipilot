# Linux File System Hierarchy (FHS)

- Vai trò của `/`, `/bin`, `/sbin`, `/etc`, `/home`, `/root`, `/var`, `/tmp`, `/usr`, `/opt`, `/dev`, `/proc`, `/sys` và `/run`
- Phân biệt configuration, application data, logs, runtime state và temporary data
- Filesystem layout có thể khác giữa distributions và minimal container images
