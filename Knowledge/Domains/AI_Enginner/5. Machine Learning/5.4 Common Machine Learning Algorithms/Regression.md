# Regression

#### Linear Regression

- Linear relationship giữa features và target
- Least-squares objective
- Coefficients và intercept
- Residual assumptions cho inference thống kê
- Multicollinearity và outliers
- Scaling không bắt buộc cho prediction nhưng hữu ích trong một số workflow

#### Ridge

- L2 regularization
- Shrink coefficients
- Hữu ích khi features tương quan
- Regularization strength cần tune
- Scaling thường quan trọng

#### Lasso

- L1 regularization
- Sparse coefficients
- Feature-selection effect
- Instability với correlated features
- Scaling thường quan trọng

#### ElasticNet

- Kết hợp L1 và L2
- Regularization strength và mixing ratio
- Hữu ích khi có nhiều correlated features
