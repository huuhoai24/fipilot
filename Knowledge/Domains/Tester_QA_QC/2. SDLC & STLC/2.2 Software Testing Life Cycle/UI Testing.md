# UI Testing

- **User Interface Testing**: controls, content, navigation, states và interaction
- **Layout Testing**: alignment, spacing, overflow, clipping và visual hierarchy
- **Responsive Testing**: behavior trên viewport, breakpoint và orientation khác nhau
- **Cross-browser Testing**: compatibility giữa rendering engines và browser versions được hỗ trợ
- **Accessibility Testing**: keyboard, semantics, focus, contrast và assistive technology
- Kiểm tra loading, empty, error, disabled và permission-dependent states
