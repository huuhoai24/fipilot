# Git Fundamentals

- **Repository**: working tree, staging area và commit history
- **Commit**: snapshot có message và parent relationships
- **Branch**: line of development độc lập
- **Merge**: kết hợp histories
- **Rebase**: replay commits và rewrite commit identities
- **Cherry-pick**: áp dụng selected commit trên branch khác
- **Stash**: lưu tạm working changes
- **Tag**: đánh dấu release hoặc milestone
