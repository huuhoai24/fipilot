# Framework Architecture

- **Test Framework**: conventions, abstractions, configuration và integrations
- **Test Runner**: discovery, execution, parallelization và result collection
- **Test Suite**: nhóm tests theo purpose, feature, risk hoặc pipeline stage
- **Test Fixtures**: reusable setup state và dependencies
- **Test Lifecycle**: initialization, setup, execution, teardown và reporting
- **Test Hooks**: before/after hooks; cần tránh hidden shared state
