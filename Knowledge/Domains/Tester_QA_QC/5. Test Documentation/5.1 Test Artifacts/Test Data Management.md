# Test Data Management

- **Test Data**: input và expected business state cho tests
- **Test Fixtures**: setup data hoặc objects có lifecycle rõ
- **Data-driven Testing** và **Parameterization**
- **External Test Data**: CSV, JSON, database hoặc services; phải versioned và validated
- **Test Data Generation**: deterministic factories, unique values và realistic constraints
- **Test Data Cleanup**: teardown, rollback, expiration hoặc isolated environments
- Không dùng production personal data nếu chưa được bảo vệ và phê duyệt
