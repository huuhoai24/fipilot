# Test Execution Pipeline

- **Smoke Test Automation**: fast checks sau build hoặc deployment
- **Regression Automation**: broader validation trước release hoặc theo schedule
- **Parallel Test Execution**: giảm duration nhưng cần test isolation
- **Test Reporting**: results, evidence, trends và links tới defects
- **Pipeline Notifications**: thông báo failure có owner và context
- Quản lý retries, timeouts, test data, environments và flaky tests
