# Accessibility Validation

- **Keyboard Navigation**: mọi chức năng cần thiết có thể dùng bằng keyboard khi applicable
- **Focus Management**: visible focus, logical order, dialogs và route changes
- **Screen Reader Compatibility**: accessible names, roles, states và announcements
- **Color Contrast**: text, controls và meaningful graphics theo criteria áp dụng
- **Semantic HTML Validation**: native elements, headings, landmarks và labels
- **ARIA Validation**: roles, properties và states hợp lệ; native HTML được ưu tiên
