# Requirement Traceability

- **Requirement Traceability Matrix (RTM)**: liên kết requirements với scenarios, test cases, execution và defects
- **Requirement Coverage**: mức độ requirements đã được review và kiểm thử
- **Change Impact Analysis**: xác định tests, data, interfaces và components bị ảnh hưởng khi requirement thay đổi
- Forward traceability từ requirement tới tests và backward traceability từ test về source
- Traceability phải hỗ trợ quyết định, không chỉ tạo spreadsheet hình thức
