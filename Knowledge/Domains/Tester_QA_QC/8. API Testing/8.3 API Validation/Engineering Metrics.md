# Engineering Metrics

- **Defect Escape Rate** và **Defect Leakage**
- **Automation Coverage**: coverage theo scenarios hoặc risks, không chỉ số lượng scripts
- **Test Effectiveness**: khả năng tests phát hiện relevant defects
- **Test Execution Metrics**: duration, pass/fail, blocked, flake và queue time
- **Mean Time to Detect (MTTD)**
- **Mean Time to Resolution (MTTR)**
- Metrics cần trend, segmentation và context để tránh kết luận sai
