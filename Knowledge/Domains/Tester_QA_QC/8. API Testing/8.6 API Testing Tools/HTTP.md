# HTTP

- **HTTP Methods**: GET, POST, PUT, PATCH, DELETE, HEAD và OPTIONS với safe/idempotent semantics phù hợp
- **Request** và **Response**: method, target, headers, body, status và timing
- **Headers**: content type, authorization, caching, correlation và custom contract headers
- **Query Parameters**: filters, pagination, sorting và optional controls
- **Path Parameters**: định danh resources và nested scope
- **Request Body** và **Response Body**: schema, content type, encoding và limits
- **Status Codes**: success, redirection, client error và server error classes
