# API Validation

- **Response Validation**: status, body, business rules, ordering, pagination và side effects
- **Schema Validation**: required fields, types, formats, enums, nullable rules và additional fields
- **Header Validation**: content type, caching, security và correlation headers
- **Authentication Validation**: missing, invalid, expired và malformed credentials
- **Error Response Validation**: consistent code, message, details, trace identifier và no sensitive leakage
- Kiểm tra positive, negative, boundary, duplicate, idempotent và concurrency scenarios
