# API Testing Tools

- **Postman**: request collections, environments, variables và assertions
- **Newman**: chạy Postman collections trong command line hoặc CI
- **REST Assured**: Java library cho API automation
- **Swagger**: ecosystem tooling cho API description và interaction; không đồng nghĩa specification
- **OpenAPI**: machine-readable specification cho HTTP APIs
- Tool không thay thế test design, security authorization hoặc contract understanding
