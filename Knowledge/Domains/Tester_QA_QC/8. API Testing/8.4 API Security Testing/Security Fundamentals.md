# Security Fundamentals

- **Authentication**: xác minh identity
- **Authorization**: xác định actions và resources identity được phép truy cập
- **Confidentiality**: ngăn disclosure trái phép
- **Integrity**: ngăn hoặc phát hiện sửa đổi trái phép
- **Availability**: bảo đảm services và data sẵn sàng khi cần
- Security testing phải có scope, authorization và safe execution rules
