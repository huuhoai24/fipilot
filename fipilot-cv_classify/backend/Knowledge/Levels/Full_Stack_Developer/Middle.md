# Full Stack Developer - Middle Level Knowledge Depth & Evaluation

### Knowledge Depth

The candidate should:

- Deeply understand the architecture of a Full Stack application.
- Analyze assumptions and limitations of solutions.
- Evaluate trade-offs among SSR, CSR, SSG and Hybrid Rendering.
- Understand concurrency, caching, consistency and scalability.
- Analyze API design, versioning and backward compatibility.
- Understand state management and data synchronization.
- Evaluate performance from frontend through backend to database.
- Analyze failure modes, bottlenecks and root causes.
- Understand observability, monitoring and logging at a system level.
- Evaluate security concerns such as XSS, CSRF, SQL Injection, SSRF and Broken Access Control.
- Assess when an architecture is no longer appropriate.

### Evaluation Focus

- Analysis.
- Assumptions.
- Failure modes.
- Root causes.
- Trade-offs.
- Performance.
- Scalability.
- Security.
- Conditions for architecture selection.
