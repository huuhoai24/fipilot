# Data Engineer - Middle Level Knowledge Depth & Evaluation

### Knowledge Depth

The candidate should:

- Deeply understand data pipeline architecture.
- Analyze assumptions and limitations of each solution.
- Compare batch, micro-batch and streaming under different conditions.
- Evaluate trade-offs among latency, throughput, consistency and cost.
- Understand distributed storage and distributed processing.
- Analyze partition strategies, skew, shuffle and bottlenecks.
- Understand data modeling for analytics and operational workloads.
- Evaluate data quality, lineage, catalog and governance.
- Understand orchestration, scheduling, dependencies and retry strategies.
- Analyze failure modes, root causes and recovery strategies.
- Understand CDC, incremental processing and idempotency.
- Assess when an architecture is no longer appropriate.

### Evaluation Focus

- Analysis.
- Assumptions.
- Failure modes.
- Root causes.
- Trade-offs.
- Distributed systems.
- Data modeling.
- Pipeline reliability.
- Conditions for solution selection.
