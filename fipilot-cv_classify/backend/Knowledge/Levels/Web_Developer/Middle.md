# Web Developer - Middle Level Knowledge Depth & Evaluation

### Knowledge Depth

The candidate should understand:

- Web application architecture and the boundaries among presentation, application, service and data layers.
- The assumptions and limitations of client-side rendering, server-side rendering, static generation and hybrid rendering.
- Browser rendering stages, including parsing, style calculation, layout, painting and compositing.
- Performance metrics and concepts such as Core Web Vitals, loading performance, runtime performance and responsiveness.
- State management, server-state synchronization, caching and optimistic updates.
- Component architecture, design systems, reusable abstractions and dependency boundaries.
- API design, versioning, error handling and backward compatibility from a web-client perspective.
- Authentication flows, authorization models, token handling and session security.
- Common web vulnerabilities, including XSS, CSRF, injection, insecure direct object references, SSRF and broken access control.
- Accessibility standards, semantic structure, keyboard interaction and assistive technology compatibility.
- Progressive enhancement, graceful degradation and cross-browser compatibility.
- Content delivery networks, browser caching, service workers and offline strategies.
- Observability concepts for web applications, including client-side logging, metrics, tracing and error reporting.
- Failure modes such as hydration mismatch, stale state, memory leaks, race conditions and network instability.
- Trade-offs among performance, maintainability, scalability, security, accessibility and user experience.
- Conditions under which a framework, rendering approach or architectural pattern is no longer appropriate.

### Evaluation Focus

- Architecture.
- Assumptions and limitations.
- Browser rendering.
- Performance.
- State and data synchronization.
- Security.
- Accessibility.
- Failure modes and root causes.
- Multi-dimensional trade-offs.
- Technology selection conditions.
