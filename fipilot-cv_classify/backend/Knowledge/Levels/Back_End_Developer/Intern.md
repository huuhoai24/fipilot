# Back End Developer - Intern Level Knowledge Depth & Evaluation

### Knowledge Depth

The candidate should:

- Correctly understand the foundational concepts of backend development.
- Know the roles of server, client, API, database and network.
- Describe the request–response flow at a high level.
- Understand the input, output and purpose of a backend component.
- Distinguish among common concepts such as process vs. thread, HTTP vs. HTTPS, and SQL vs. NoSQL.
- Know the basic functions of routing, middleware, controller, service and repository.
- Understand CRUD operations and the meaning of common HTTP methods.
- Know data types, data structures and basic complexity.
- Understand primary key, foreign key, index and transaction at a conceptual level.
- Recognize common errors such as invalid input, null reference, duplicate data and unauthorized access.
- Know basic security principles such as validation, authentication and not storing plaintext passwords.
- Understand logging, testing, version control and deployment at a conceptual level.
- No deep analysis of scalability, distributed systems or architecture trade-offs is expected.

### Evaluation Focus

- Definitions.
- Purpose.
- Components.
- General request–response flow.
- Concept differentiation.
- Common errors.
- Foundational knowledge of APIs, databases and HTTP.
