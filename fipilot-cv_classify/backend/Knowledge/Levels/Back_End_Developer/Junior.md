# Back End Developer - Junior Level Knowledge Depth & Evaluation

### Knowledge Depth

The candidate should:

- Understand the operating mechanisms of a standard backend application.
- Explain how a request flows through routing, middleware, business logic, data access and response.
- Understand separation of concerns among controller, service, domain and repository.
- Explain why validation, authentication, authorization and error handling are necessary.
- Understand REST principles, resource design, HTTP methods, status codes and basic idempotency.
- Compare session-based authentication and token-based authentication.
- Understand JWT, OAuth 2.0 and refresh tokens at a basic mechanistic level.
- Understand the relational model, normalization, joins, indexes and transactions.
- Explain the impact of indexes on read performance and write cost.
- Understand ACID, isolation levels and common anomalies at a basic level.
- Compare SQL and NoSQL based on data model and access pattern.
- Understand caching, connection pooling, pagination and rate limiting at a mechanistic level.
- Understand synchronous and asynchronous processing.
- Understand queues, background jobs and retry at a conceptual level.
- Understand how unit tests, integration tests and API tests differ.
- Identify common errors such as N+1 queries, simple race conditions, SQL injection, broken authorization and timeouts.
- Understand logging, configuration, dependency management and environment separation.
- Explain basic trade-offs among simplicity, performance and maintainability.

### Evaluation Focus

- Mechanisms.
- Causes.
- Basic assumptions.
- Method comparison.
- Simple trade-offs.
- Request–response flow.
- Basic data consistency.
- Security fundamentals.
- Common backend errors.
