# Tester QA QC - Junior Level Knowledge Depth & Evaluation

### Knowledge Depth

The candidate should understand:

- The mechanisms behind different testing techniques.
- Functional, integration, system, regression, smoke and sanity testing.
- Boundary Value Analysis, Equivalence Partitioning and Decision Table Testing.
- Risk-based testing concepts.
- Test design techniques and coverage concepts.
- Requirement traceability and requirement validation.
- Defect lifecycle and defect prioritization.
- API, database and UI testing concepts.
- Basic test automation principles.
- CI/CD from a testing perspective.
- Basic security and performance testing concepts.
- Trade-offs between manual and automated testing.

### Evaluation Focus

- Testing mechanisms.
- Test design.
- Coverage.
- Requirement validation.
- Defect analysis.
- Automation fundamentals.
- Basic trade-offs.
