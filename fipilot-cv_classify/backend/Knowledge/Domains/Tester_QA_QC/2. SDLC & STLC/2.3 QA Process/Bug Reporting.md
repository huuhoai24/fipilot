# Bug Reporting

- **Bug Report**: title rõ, impact, preconditions, steps và evidence
- **Reproduction Steps**: tối thiểu, deterministic và đủ để tái hiện
- **Expected Result**: behavior theo requirement, design hoặc accepted rule
- **Actual Result**: behavior quan sát được
- **Attachments**: screenshots, videos, logs, traces hoặc network evidence có liên quan
- **Environment Information**: build, browser, OS, device, account, data và configuration
- Không đưa secrets hoặc sensitive personal data vào report
