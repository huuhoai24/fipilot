# Test Execution Documents

- **Test Log**: record về execution time, environment, build, tester và events quan trọng
- **Execution Report**: kết quả pass, fail, blocked, not run và evidence
- **Defect Report**: mô tả defect đủ để triage và reproduce
- **Test Summary Report**: tổng hợp scope, coverage, results, risks và recommendation
- Phân biệt test failure, product defect, environment issue và test-script defect
