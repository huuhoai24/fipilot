# Test Artifacts

- **Test Strategy**: principles, test levels, techniques, tooling, environments và governance
- **Test Plan**: scope, objectives, resources, schedule, risks, entry và exit criteria
- **Test Scenario**: high-level flow hoặc condition cần được kiểm thử
- **Test Case**: preconditions, data, steps, expected result và traceability
- **Test Script**: executable manual hoặc automated sequence
- **Test Suite**: nhóm tests theo feature, level, risk hoặc execution purpose
- Artifacts phải versioned, maintainable và có owner
