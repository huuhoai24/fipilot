# Security Testing Fundamentals

- **Security Assessment**: đánh giá controls, exposures và weaknesses theo scope
- **Threat Modeling**: assets, actors, trust boundaries, threats và mitigations
- **Attack Surface**: endpoints, inputs, integrations, identities và infrastructure được expose
- **Risk Assessment**: likelihood, impact, exploitability và business context
- **Security Verification**: xác nhận controls hoạt động như thiết kế
- Chỉ thực hiện tests trong phạm vi được ủy quyền
