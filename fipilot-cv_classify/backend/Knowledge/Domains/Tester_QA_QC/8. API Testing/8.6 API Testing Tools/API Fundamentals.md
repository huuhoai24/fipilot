# API Fundamentals

- **REST API**: resources, HTTP methods, representations, status codes và stateless semantics
- **SOAP API**: XML messages, envelopes, WSDL và protocol-level faults
- **GraphQL**: schema, queries, mutations, variables, errors và partial data
- **gRPC**: strongly typed RPC contracts, unary hoặc streaming calls và status codes
- **WebSocket**: persistent bidirectional connection, messages, reconnect và lifecycle
- Xác định contract, version, authentication và backward compatibility của từng API
