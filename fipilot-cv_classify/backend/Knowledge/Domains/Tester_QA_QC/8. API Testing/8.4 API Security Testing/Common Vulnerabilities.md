# Common Vulnerabilities

- **SQL Injection**: input thay đổi cấu trúc SQL; kiểm tra parameterization và validation
- **Cross-site Scripting (XSS)**: untrusted content được thực thi trong browser
- **Cross-site Request Forgery (CSRF)**: lạm dụng authenticated browser để gửi request thay đổi state
- **Broken Authentication**: lỗi trong login, session, recovery hoặc credential lifecycle
- **Broken Access Control**: thiếu kiểm tra permission hoặc resource ownership
- **Security Misconfiguration**: defaults, headers, permissions hoặc services không an toàn
- Kiểm tra positive và negative authorization cho từng role và tenant
