# Security Standards

- **OWASP Top 10**: danh sách awareness về nhóm rủi ro web phổ biến, không phải checklist đầy đủ
- **Secure Coding**: coding practices giảm injection, exposure và misuse
- **Input Validation**: type, format, length, range và allow-list tại trust boundaries
- **Output Encoding**: encode theo HTML, attribute, URL, JavaScript hoặc SQL context phù hợp
- Kết hợp review, automated scanning và manual verification
