# Engineering Practices

- **Test Maintainability**: clear intent, low duplication và stable abstraction
- **Automation Maintainability**: modular code, deterministic data và controlled dependencies
- **Code Review**: correctness, readability, reliability và security
- **Documentation Standards**: templates, ownership, versioning và review
- **Continuous Learning**: cập nhật domain, tools, defects và system behavior
- Ưu tiên prevention và fast feedback hơn tăng số lượng tests thiếu giá trị
