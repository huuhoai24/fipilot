# Cloud Fundamentals

- **Cloud Computing**: on-demand shared compute, storage, network và managed services
- **Virtual Machines**: isolated guest operating systems trên virtualized infrastructure
- **Object Storage**: key-based storage cho files/artifacts, không phải POSIX filesystem
- **Environment Management**: configuration, access, lifecycle, data và cost
- Hiểu shared responsibility và tránh dùng production resources cho tests không kiểm soát
