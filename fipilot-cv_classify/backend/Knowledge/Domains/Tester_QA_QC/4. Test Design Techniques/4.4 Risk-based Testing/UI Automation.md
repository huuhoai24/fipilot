# UI Automation

- **Selenium**: browser automation qua WebDriver ecosystem
- **Playwright**: cross-browser automation với auto-waiting, contexts và tracing
- **Cypress**: browser-focused testing với execution model và debugging tích hợp
- **WebDriver**: standard/protocol family điều khiển browser từ external process
- Chọn stable selectors, tránh fixed sleeps và kiểm tra user-visible behavior
