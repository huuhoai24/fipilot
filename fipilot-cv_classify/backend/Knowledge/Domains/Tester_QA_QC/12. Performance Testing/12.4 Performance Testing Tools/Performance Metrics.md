# Performance Metrics

- **Transactions Per Second (TPS)** và **Requests Per Second (RPS)**
- **CPU Usage** và saturation
- **Memory Usage**, allocation, garbage collection và leaks
- **Disk I/O**: throughput, latency, queue và IOPS
- **Network I/O**: bandwidth, errors, drops và retransmissions
- Kết hợp application, database, cache và infrastructure metrics để tìm bottleneck
