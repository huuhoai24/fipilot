# Performance Testing Tools

- **Apache JMeter**: protocol-level load testing và extensible test plans
- **Gatling**: code-based performance testing trên JVM ecosystem
- **k6**: script-based load testing với JavaScript API
- **Locust**: Python-based load-generation framework
- Tool selection dựa trên protocol, workload model, scalability và team skills
- Load generators phải được theo dõi để tránh chúng trở thành bottleneck
