# Performance Test Types

- **Load Testing**: behavior dưới expected workload
- **Stress Testing**: vượt capacity để xác định limits và failure behavior
- **Spike Testing**: tăng hoặc giảm workload đột ngột
- **Endurance Testing**: chạy dài để phát hiện leaks, degradation và accumulation
- **Volume Testing**: behavior với lượng data lớn
- **Scalability Testing**: khả năng tăng capacity khi resources hoặc instances thay đổi
- Mỗi test phải có workload model, acceptance thresholds và monitoring plan
