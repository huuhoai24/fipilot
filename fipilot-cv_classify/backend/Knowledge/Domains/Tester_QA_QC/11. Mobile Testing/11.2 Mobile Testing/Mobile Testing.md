# Mobile Testing

- **Device Compatibility**: hardware, OS version, chipset, sensors và vendor customizations
- **Screen Resolution**: density, safe areas, cutouts và text scaling
- **Orientation**: portrait, landscape và state preservation khi rotation
- **Touch Gestures**: tap, long press, swipe, pinch và multi-touch
- **Battery Consumption**: background work, sensors, network và wake locks
- **Network Changes**: Wi-Fi, cellular, offline, weak signal và network switching
- Kiểm tra permissions, interruptions, background/foreground và low-resource conditions
