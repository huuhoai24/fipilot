# Mobile Fundamentals

- **Native Applications**: ứng dụng xây cho platform cụ thể và sử dụng native APIs
- **Hybrid Applications**: web content được đóng gói trong native container hoặc bridge
- **Progressive Web Apps (PWA)**: web app có installability, service worker và offline capabilities tùy implementation
- **Responsive Web Applications**: web UI thích ứng viewport nhưng không nhất thiết có native capabilities
- Mỗi loại application có distribution, permission và lifecycle khác nhau
