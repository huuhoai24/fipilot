# Mobile Platforms

- **Android Testing**: devices, API levels, permissions, activities và background restrictions
- **iOS Testing**: devices, iOS versions, permissions và application lifecycle
- **Emulator**: mô phỏng platform và hardware behavior ở mức software
- **Simulator**: thường mô phỏng OS/application environment nhưng không đầy đủ hardware behavior
- **Real Device Testing**: xác minh performance, sensors, vendor differences và real network behavior
- Kết hợp virtual devices và real devices theo risk matrix
