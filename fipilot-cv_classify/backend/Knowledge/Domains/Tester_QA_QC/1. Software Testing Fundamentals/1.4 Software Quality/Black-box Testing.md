# Black-box Testing

- **Equivalence Partitioning**: chia input hoặc output domain thành các partitions được kỳ vọng có behavior tương tự
- **Boundary Value Analysis**: tập trung vào boundaries và giá trị ngay dưới, tại hoặc trên boundary
- **Decision Table Testing**: kiểm thử combinations của conditions và resulting actions
- **State Transition Testing**: kiểm thử states, events, transitions, guards và invalid transitions
- **Cause-effect Graph**: mô hình hóa quan hệ logic giữa input conditions và output effects
- **Use Case Testing**: xây tests từ user goals, main flow, alternative flow và exception flow
- Kỹ thuật black-box không yêu cầu biết cấu trúc code bên trong
