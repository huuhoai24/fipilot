# Quality Assurance

- **Quality Gates**: measurable checks trước promotion hoặc release
- **Process Improvement**: thay đổi process dựa trên evidence và root causes
- **Quality Metrics**: defect, coverage, reliability, performance và delivery indicators
- **Continuous Improvement**: inspect results, thử changes và theo dõi outcome
- Không tối ưu metric đơn lẻ theo cách làm giảm product value hoặc team behavior
