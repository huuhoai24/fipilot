# Requirement Types

- **Business Requirements**: mục tiêu hoặc outcome cấp cao mà solution cần hỗ trợ
- **Functional Requirements**: chức năng, behavior, input, processing và output hệ thống phải cung cấp
- **Non-functional Requirements**: performance, reliability, security, usability, compatibility và các quality constraints
- **User Stories**: mô tả nhu cầu và giá trị từ góc nhìn user hoặc stakeholder
- **Acceptance Criteria**: điều kiện cụ thể và testable để requirement hoặc story được chấp nhận
- Phân biệt requirement, design decision và implementation detail
