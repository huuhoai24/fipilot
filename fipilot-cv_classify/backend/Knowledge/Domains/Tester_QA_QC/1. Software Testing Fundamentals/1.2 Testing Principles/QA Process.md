# QA Process

- **Test Strategy**: định hướng kiểm thử cấp tổ chức, product hoặc program
- **Test Plan**: kế hoạch cụ thể cho release, project hoặc test level
- **Test Schedule**: milestones, dependencies, execution windows và resource allocation
- **Entry Criteria**: điều kiện tối thiểu để bắt đầu một test activity
- **Exit Criteria**: điều kiện để kết thúc test activity hoặc hỗ trợ release decision
- **Risk Assessment**: đánh giá likelihood, impact và test priority
- Criteria phải measurable và phù hợp context thay vì chỉ mang tính hình thức
