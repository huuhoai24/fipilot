# Software Testing Life Cycle

- **Requirement Analysis**: xác định testable requirements, risks, dependencies và gaps
- **Test Planning**: xác định scope, approach, resources, estimates, schedule và exit criteria
- **Test Case Design**: thiết kế scenarios, cases, data và expected results
- **Test Environment Setup**: chuẩn bị systems, services, accounts, configuration và data
- **Test Execution**: thực hiện tests, ghi evidence và đánh giá actual results
- **Defect Reporting**: ghi nhận, phân loại, theo dõi và xác minh defects
- **Test Closure**: tổng hợp coverage, remaining risks, metrics, lessons learned và artifacts
- Các phase có thể overlap hoặc lặp lại trong Agile delivery
