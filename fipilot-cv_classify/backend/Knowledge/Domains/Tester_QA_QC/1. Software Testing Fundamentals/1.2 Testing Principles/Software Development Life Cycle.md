# Software Development Life Cycle

- **Requirements Analysis**: làm rõ business needs, functional behavior, constraints và acceptance
- **Design**: xác định architecture, components, data và interfaces
- **Development**: hiện thực code, configuration và supporting artifacts
- **Testing**: đánh giá software theo requirements, risks và quality attributes
- **Deployment**: đưa release vào target environment với validation và rollback plan
- **Maintenance**: sửa defects, cập nhật, theo dõi và cải tiến hệ thống
- QA tham gia xuyên suốt SDLC thay vì chỉ ở cuối development
