# Framework Patterns

- **Page Object Model (POM)**: object đại diện page hoặc component behavior
- **Screen Object Model**: tương đương POM cho mobile screens
- **Page Factory**: factory/annotation-based element initialization trong một số tools
- **Fluent Interface**: chainable API tăng readability nhưng không nên che giấu failures
- **Factory Pattern**: tạo drivers, clients, users hoặc data theo configuration
- **Builder Pattern**: tạo test objects hoặc requests phức tạp với defaults có kiểm soát
