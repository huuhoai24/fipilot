# Collaboration

- **Pull Request** và **Merge Request**: review, discussion và automated checks
- **Code Review**: correctness, maintainability, reliability và security của test code
- **Merge Conflict**: xung đột changes cần hiểu intent trước khi resolve
- **Git Flow**: workflow nhiều long-lived và release branches
- **Trunk-based Development**: tích hợp thường xuyên vào trunk với short-lived branches
- Không commit secrets, generated reports lớn hoặc environment-specific credentials
