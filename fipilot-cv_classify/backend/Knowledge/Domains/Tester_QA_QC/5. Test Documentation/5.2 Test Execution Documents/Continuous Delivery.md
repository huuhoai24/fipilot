# Continuous Delivery

- **Continuous Delivery (CD)**: artifact luôn ở trạng thái có thể triển khai
- **Deployment Pipeline**: promote cùng immutable artifact qua environments
- **Release Pipeline**: approvals, release strategy, rollout và rollback
- **Test Pipeline**: tổ chức tests theo speed, scope và confidence
- Phân biệt deployment với release bằng feature flags hoặc traffic controls khi cần
