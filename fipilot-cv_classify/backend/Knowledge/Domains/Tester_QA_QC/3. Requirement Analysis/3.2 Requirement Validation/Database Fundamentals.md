# Database Fundamentals

- **Tables**: rows, columns, types, keys và constraints
- **Views**: virtual query-based representation và security implications
- **Relationships**: one-to-one, one-to-many và many-to-many
- **Constraints**: primary key, foreign key, unique, check và nullability
- **Stored Procedures**: server-side database routines với inputs, outputs và transaction behavior
- **Triggers**: logic tự động chạy khi database events xảy ra
- Xác minh migrations, default values, cascade behavior và schema compatibility
