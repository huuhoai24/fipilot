# SQL

- **SELECT**: retrieval, projection, filtering và ordering
- **INSERT**, **UPDATE** và **DELETE**: data changes, validation và affected rows
- **JOIN**: kết hợp data theo relationships; kiểm tra duplicates và missing matches
- **GROUP BY** và **HAVING**: aggregation và group filtering
- **Subquery**: nested query và correlated behavior ở mức cần thiết
- Kiểm tra parameterized queries và tránh SQL injection
