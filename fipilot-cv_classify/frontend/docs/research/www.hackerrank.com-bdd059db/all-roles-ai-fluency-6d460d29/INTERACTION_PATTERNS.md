# Interaction Patterns

- Profile trigger: click opens a menu. Directly observed menu items are listed in `BEHAVIORS.md`.
- Header icon buttons: pointer cursor; observed transition is `color 0.2s ease-in-out, backgroundColor 0.2s ease-in-out, borderColor 0.2s ease-in-out`.
- CTA: pointer cursor; observed transition is `color 0.2s ease-in-out, backgroundColor 0.2s ease-in-out, borderColor 0.2s ease-in-out`.
- Media controls: pointer cursor; observed transition is `0.1s ease-in-out`.

No hover visual delta was asserted because no computed hover state was directly captured.
