# FiPilot project report plan

The report is an as-built account of the connected FiPilot application. The example thesis document is used only for chapter organization and page-layout reference.

## Included chapters

1. Project Introduction
2. Project Management Plan
3. Existing Systems and Theoretical Background
4. AI Methodology and Solution
5. System Design and Implementation
6. Software Requirements Specification
7. Software Testing
8. Deliverables and User Guide
9. Conclusion
10. References and runtime appendices

## Evidence rule

Only code paths connected to `backend/gateway/main.py` and production frontend routes are described as system behavior. Repository specifications can identify a limitation but do not make an unconnected feature part of the implementation.

## Figure rule

Each diagram has a dedicated source under `report/diagrams`, is rendered at high resolution, is bounded to the printable page, and is separated from adjacent floats. Wide, unreadable process chains are decomposed into focused diagrams.
