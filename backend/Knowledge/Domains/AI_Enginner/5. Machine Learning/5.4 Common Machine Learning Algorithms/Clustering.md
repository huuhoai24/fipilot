# Clustering

#### KMeans

- Centroid-based clustering
- Euclidean distance
- Cần chọn `k`
- Scaling
- Nhạy với initialization và outliers
- Phù hợp clusters gần spherical

#### DBSCAN

- Density-based clustering
- `eps` và `min_samples`
- Noise points
- Clusters hình dạng bất kỳ
- Khó chọn parameters khi density thay đổi hoặc dimension cao

#### Hierarchical Clustering

- Agglomerative/divisive concepts
- Linkage methods
- Dendrogram
- Distance metric
- Computational cost
