# Regression Metrics

#### MAE

- Mean absolute error
- Cùng đơn vị với target
- Ít nhạy với large errors hơn MSE

#### MSE

- Mean squared error
- Phạt large errors mạnh
- Đơn vị bị bình phương

#### RMSE

- Square root của MSE
- Cùng đơn vị với target
- Vẫn nhạy với outliers

#### R²

- Variance explained tương đối với mean baseline
- Có thể âm trên test data
- Không phản ánh absolute error scale
