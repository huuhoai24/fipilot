# Automation Best Practices

- **Page Object Model (POM)**: tách page interactions khỏi test intent
- **Page Factory**: object-creation/element-initialization pattern phổ biến trong một số Selenium frameworks; không bắt buộc
- **Reusable Components**: common actions, API clients, fixtures và assertions có responsibility rõ
- **Test Data Management**: deterministic setup, isolation, cleanup và privacy
- Tests độc lập, repeatable, observable và có failure messages hữu ích
- Tự động hóa ở level thấp nhất có thể cung cấp đủ confidence
