# Automation Fundamentals

- **Test Automation**: tự động setup, action, validation, reporting và cleanup
- **Automation Framework**: cấu trúc, conventions, utilities và integrations cho automated tests
- **Test Scripts**: executable test logic với assertions rõ
- **Data-driven Testing**: cùng test logic chạy trên nhiều datasets
- **Keyword-driven Testing**: test được biểu diễn bằng keywords/actions ở mức abstraction cao
- **Hybrid Framework**: kết hợp nhiều patterns dựa trên nhu cầu
- Không tự động hóa test chỉ vì test có thể tự động hóa
