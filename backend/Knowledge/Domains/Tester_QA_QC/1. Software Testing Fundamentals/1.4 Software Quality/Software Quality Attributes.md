# Software Quality Attributes

- **Functionality**: behavior và capabilities đáp ứng needs
- **Reliability**: hoạt động đúng và ổn định
- **Usability**: user đạt mục tiêu hiệu quả và hài lòng
- **Maintainability**: dễ phân tích, sửa đổi và kiểm thử
- **Portability**: khả năng chuyển hoặc thích nghi environment
- **Efficiency**: performance tương ứng resources sử dụng
- **Compatibility**: coexistence và interoperability
- **Security**: bảo vệ data, identities và services
