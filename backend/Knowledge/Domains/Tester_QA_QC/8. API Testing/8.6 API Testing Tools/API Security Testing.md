# API Security Testing

- **Authentication Testing**: login/token issuance, invalid credentials, lockout và session lifecycle
- **Authorization Testing**: object-level, function-level, role và tenant boundaries
- **JWT Validation**: signature, algorithm, issuer, audience, expiry và key rotation
- **OAuth Testing**: scopes, redirect URI, state, PKCE và token use
- **Token Expiration**: expiry, renewal, refresh rotation và revocation
- **Session Validation**: fixation, invalidation, cookie security và concurrent sessions
- Không kiểm thử security trên production khi chưa được ủy quyền
