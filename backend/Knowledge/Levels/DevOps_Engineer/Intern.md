# DevOps Engineer - Intern Level Knowledge Depth & Evaluation

### Knowledge Depth

The candidate should:

- Understand the role of DevOps within the Software Development Lifecycle.
- Understand foundational concepts such as CI, CD, Infrastructure, Deployment and Automation.
- Distinguish among Development, Operations and DevOps.
- Understand the purpose of version control, build, test and deployment.
- Describe the basic flow from source code to production.
- Understand the concepts of container, image and registry at a high level.
- Know the purpose of Docker, Kubernetes, Virtual Machine and Cloud.
- Understand logging, monitoring and alerting at a conceptual level.
- Know the role of Infrastructure as Code (IaC).
- Recognize common errors such as deployment failure, configuration mismatch and service unavailable.
- Understand basic security principles such as secret management and least privilege.
- No analysis of distributed systems or cloud architecture is expected.

### Evaluation Focus

- Definitions.
- Purpose.
- Components.
- CI/CD flow.
- Concept differentiation.
- Foundational knowledge of Cloud and Container.
