# Tester QA QC - Middle Level Knowledge Depth & Evaluation

### Knowledge Depth

The candidate should understand:

- Test strategy design and quality engineering concepts.
- Assumptions and limitations of different testing approaches.
- Risk analysis and test prioritization.
- Failure modes, root causes and defect prevention.
- Test architecture and automation strategy.
- API, database, distributed system and microservice testing.
- Performance, scalability and reliability testing concepts.
- Observability from a testing perspective.
- Test data management and environment management.
- Security testing concepts and common application vulnerabilities.
- Metrics for evaluating software quality.
- When a testing strategy is no longer appropriate.

### Evaluation Focus

- Analysis.
- Assumptions.
- Failure modes.
- Root causes.
- Test strategy.
- Automation strategy.
- Reliability.
- Security.
- Quality metrics.
