# Web Developer - Intern Level Knowledge Depth & Evaluation

### Knowledge Depth

The candidate should understand:

- The role of a Web Developer within the Software Development Lifecycle.
- Fundamental concepts of the Web, including browsers, servers, clients, URLs and web pages.
- The purposes of HTML, CSS and JavaScript.
- The basic structure of an HTML document and the role of semantic elements.
- Core CSS concepts such as selectors, the box model, layout, positioning and responsive design.
- Basic JavaScript concepts such as variables, functions, conditions, loops, objects and events.
- The HTTP request–response lifecycle at a high level.
- The differences between static and dynamic websites.
- The purpose of APIs, databases, version control, testing and deployment.
- Basic accessibility, usability and web security concepts.
- Common browser-side errors such as invalid markup, broken styles, missing resources and JavaScript runtime errors.
- No deep knowledge of frameworks, architecture or distributed systems is expected.

### Evaluation Focus

- Definitions.
- Purpose.
- Core web technologies.
- Basic browser–server interaction.
- Fundamental web terminology.
- Basic accessibility and security awareness.
