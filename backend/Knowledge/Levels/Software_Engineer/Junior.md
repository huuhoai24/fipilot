# Software Engineer - Junior Level Knowledge Depth & Evaluation

### Knowledge Depth

The candidate should:

- Understand the operating mechanisms of common data structures and algorithms.
- Explain time complexity and space complexity of basic approaches.
- Understand Object-Oriented Programming, Functional Programming and Procedural Programming at a mechanistic level.
- Understand SOLID, DRY, KISS and YAGNI at a conceptual level.
- Distinguish among interface, abstraction, inheritance, composition and polymorphism.
- Understand exception handling, memory management and resource lifecycle.
- Understand concurrency, parallelism, thread, process and asynchronous programming at a basic level.
- Understand unit test, integration test, end-to-end test and the test pyramid.
- Understand API, database, transaction, caching and message queue at a high level.
- Understand dependency management, package management and semantic versioning.
- Identify code smell, tight coupling, duplicated logic and poor separation of concerns.
- Explain basic trade-offs among readability, performance, maintainability and complexity.
- Understand common security risks such as injection, broken authentication and insecure data handling.

### Evaluation Focus

- Mechanisms.
- Causes.
- Basic assumptions.
- Method comparison.
- Basic trade-offs.
- Data structures and algorithms.
- Code quality.
- Basic testing and security.
