# Full Stack Developer - Junior Level Knowledge Depth & Evaluation

### Knowledge Depth

The candidate should:

- Understand the operating mechanisms of Frontend, Backend and Database.
- Explain rendering, routing, state management and API communication.
- Understand the request lifecycle and end-to-end data flow.
- Compare REST and GraphQL at a basic level.
- Understand authentication, authorization, JWT and session.
- Understand SQL, NoSQL, transaction and indexing at a mechanistic level.
- Understand caching, pagination and asynchronous processing.
- Understand component architecture and separation of concerns.
- Identify common errors related to performance, security and data consistency.
- Explain basic trade-offs among performance, maintainability and complexity.

### Evaluation Focus

- Mechanisms.
- Causes.
- Basic assumptions.
- Method comparison.
- Basic trade-offs.
- Data flow.
- Basic security.
